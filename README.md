This repository contains coding scripts associated with the paper:

> Groen-Van Schooten and Franco Fernandez et al. *Mapping the complexity and diversity of tertiary lymphoid structures in primary and peritoneal metastatic gastric cancer*. Journal for ImmunoTherapy of Cancer (2024). DOI: 10.1136/jitc-2024-009243.

## About this repository

This repository was created after publication of the study to provide additional insight into the code used for the analyses described in the paper. The repository was not part of the original publication and is provided as a retrospective resource to improve transparency and reproducibility.

NOTE: This repository contains only the code; no data files are included.

The scripts are organized according to their assigned prefix numbers and should generally be followed in the following folder order:

1. `cohort_1`
2. `cohort_2`
3. `combined_cohorts`

The prefix numbers of the scripts indicate the intended order in which the analyses were performed.

## About the workflows and code

Some of the scripts and workflows in this repository are based on the original NanoString workflows used for the analyses. These pipelines were subsequently adapted and further developed, in part, by employees of USEQ.

The workflows were subsequently further adapted for this project. I personally modified parts of the existing pipelines and developed new code for several of the analyses presented in the paper.

As this was my first coding project, the organization and structure of the code may not always reflect how I would approach a similar project today. Some scripts therefore contain exploratory code, project-specific adaptations, or workflows that could be further streamlined.

## Note

This repository is provided primarily for transparency and reproducibility of the published analyses. The code should therefore be considered in the context of the original study and its methods.
